# Distributor Panel (React)

## Setup
1. `npm install`
2. `npm start` (port 3001)

## Env
- `REACT_APP_API_BASE_URL=http://localhost:6500`
- `REACT_APP_API_PREFIX=/distributor`
- API → `http://localhost:6500/distributor`

## Routes wired
- POST `/login`, `/register`
- GET `/get-dashboard`, `/get-profile`, `/get-notifications`
- POST `/update-profile`

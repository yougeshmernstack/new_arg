# Franchise Panel (React)

## Setup
1. `npm install`
2. `npm start` (port 3002)

## Env
- `REACT_APP_API_BASE_URL=http://localhost:6500`
- `REACT_APP_API_PREFIX=/franchise`
- API → `http://localhost:6500/franchise`

## Routes wired
- POST `/login`
- GET `/get-dashboard`, `/get-profile`, `/get-notifications`
- POST `/update-profile`
